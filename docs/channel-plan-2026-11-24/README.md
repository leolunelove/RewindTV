# RewindTV — 100-channel programming proposal

Updated 25 November 2026. **Editorial plan, not a published or playable episode schedule.**

100 destinations: **90 permanent + 10 Christmas**. All 37 current local-release channel numbers and names remain intact, including the original 33. There are 63 proposed additions: 54 permanent and nine seasonal. Existing Christmas TV on channel 14 is the tenth seasonal channel; the new seasonal channels are 92–100.

The right target is 100 distinct reasons to tune in, not 100 thin playlists. Existing channel names referring to broadcasters describe the era/collection; this proposal does not imply affiliation or permission to redistribute their programmes. No proposed title, upload, licence, runtime or region availability has been verified by writing this plan.

## The television day

Use 06:00–06:00 Europe/Gibraltar as the editorial viewing day. The eight windows below cover a full 24-hour day. They are programming strands, not promises that an episode starts exactly on the boundary. A running programme always finishes. A new strand takes effect at the next complete programme boundary. Actual Guide times must be derived from media durations. The existing Tuesday weekly anchor and first-ten fixed schedules are not changed by this document.

| Window | Programming intention |
| --- | --- |
| 06:00–09:00 | Easy entry; shorter or gentler selections within the channel’s remit |
| 09:00–12:00 | A different show or strand; keep serials in order |
| 12:00–15:00 | Discovery and breadth; avoid replaying breakfast episodes |
| 15:00–18:00 | Strong after-school/family block where appropriate |
| 18:00–20:00 | Familiar favourites and accessible starting points |
| 20:00–23:00 | The evening showcase: features, specials or the strongest series |
| 23:00–02:00 | Deeper cuts; age-appropriate to the channel, not automatically adult |
| 02:00–06:00 | Fresh overnight selection and serial continuation; no automatic daytime rerun |

## Schedule generation rules

1. Keep the first ten on fixed weekly schedules. Leave the others as deterministic continuous mixes unless a separate schedule migration is approved. Generate an inspectable 24-hour Guide from the same playback plan; do not introduce a second scheduler.
2. Build plans from eligible, enabled sources and measured runtimes. Every programme has a canonical story identity, source identity, completeness status, audio/subtitle language and source/rights evidence. A long upload is not automatically a full episode.
3. Deduplicate by story, not YouTube ID. A compilation covering an episode reserves that story too. Keep multipart stories adjacent. Check existing singles before sourcing replacements.
4. Sequence story-dependent series in order. Select randomly between show runs, rather than randomly breaking the story order. Limit normal general-channel runs to two episodes of one show; explicitly label franchise marathons.
5. Hold a canonical episode out of the same channel for at least 24 hours where the inventory permits. Aim for a seven-day gap in the main ten. Target 72 unique hours for a new general channel and at least 48 for a Christmas channel before making it a separate destination. These are proposed launch gates, not claims about current inventory. Thin concepts remain Library collections or scheduled blocks.
6. Across related channels, avoid the same story within a rolling six-hour window where possible. A Christmas episode placed on Christmas Cartoons should not immediately run on the seasonal flagship. Scarcity must be visible in the planning report, not hidden by disabling deduplication.
7. Films run in full. Select a suitable next feature using its actual duration; never cut a film for an hourly boundary. Use reviewed shorts only when useful. No silent padding or invented listings.
8. Adverts belong between complete episodes or films. Keep them short, optional and appropriately sourced. Do not splice inside a programme or count repeated adverts as unique programme depth. Provider-served adverts remain outside our scheduling control.
9. Separate source unavailability from network/autoplay errors. A playback skip advances to the next eligible item without silently rewriting the published fixed plan. Guide and player must describe that same next item and any live recovery accurately.
10. Local country selection/known restrictions filter eligibility. Playback on one test network is not worldwide clearance. Automated checks and Archive hosting do not establish copyright permission. Publish only reviewed sources within the existing rights policy.
11. Build timelines from absolute timestamps, then format Europe/Gibraltar times. Daylight-saving changes can produce a 23- or 25-hour local day; never assume every date is exactly 86,400 seconds.
12. Keep the catalogue loaded once. A larger Guide should window its rows and use text/cheap logos, not start 100 hidden players or prefetch every thumbnail/video. Preserve one active playback source and the existing Library/live separation.
